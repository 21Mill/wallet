# Tu wallet Lightning (sitio estático)

Página estática de la comunidad para obtener una wallet Lightning por invitación.
Generada automáticamente: no la edites a mano.

- **No contiene secretos.** Solo la clave pública del worker y la lista de relays (están dentro de `main.js`).
- Los secretos de conexión se generan bajo demanda, cifrados de extremo a extremo, y nunca pasan por este repositorio.
- Licencias de las librerías incluidas: `main.js.LEGAL.txt`.
